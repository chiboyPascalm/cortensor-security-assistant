# Demo Runbook

1. Run scanner: `.venv/bin/python app.py`
2. Scan a contract: `.venv/bin/python app.py path/to/Contract.sol`
3. Run tests: `.venv/bin/python -m unittest discover -s tests -v`
4. Optional AI explanation: `.venv/bin/python app.py --ai`

A pattern match does not prove a vulnerability. AI output can be wrong. This prototype does not replace a full security audit. Never display API keys during a demo.
